## 1. find -exec 세미콜론 이스케이프

### Question
(덤프 문제 아님 — 실습 중 직접 마주친 에러)
`find / -user jacques -exec cp -a {} /root/testfile ;` 실행 시
`find: missing argument to '-exec'` 에러 발생

### My Solution
```bash
find / -user jacques -exec cp -a {} /root/testfile \;
```

### Verification
```bash
[root@node1 vagrant]# find / -user jacques -exec cp -a {} /root/testfile ;
find: missing argument to `-exec'
[root@node1 vagrant]# find / -user jacques -exec cp -a {} /root/testfile \;
(정상 실행됨)
```

### 내가 헷갈렸던 것 / 배운 것
- bash가 `;`를 명령어 구분자로 먼저 소비해버려서, find에게 `;`가 전달되지 않음
- `\;`(또는 `';'`)로 이스케이프해야 find가 "exec 명령어 끝" 표시로 인식
- `-exec cmd {} +`는 여러 파일을 한 번에 묶어 실행 (find가 xargs처럼 동작)
- 부가로: 대상 경로가 파일 하나(`/root/testfile`)면 여러 파일 매칭 시 덮어써서 마지막 파일만 남음 → 여러 파일 모으려면 디렉터리로 지정 필요

## 2. tar 압축 해제 시 절대경로 스트리핑

### Question
(덤프 문제 아님 — 실습 중 직접 마주친 현상)
`/root`에서 `tar -xvjf /root/backup.tar.bz2` 실행 시 `/root/usr/local/...` 형태로 풀림 (원래 경로는 `/usr/local/...`)

### My Solution
```bash
# 목적이 원래 위치(/usr/local) 복원이면
cd /
tar -xvjf /root/backup.tar.bz2

# 풀기 전 내용만 미리 확인하고 싶으면
tar -tvjf /root/backup.tar.bz2 | head
```

### Verification
```bash
[root@node1 ~]# tar -xvjf /root/backup.tar.bz2
usr/local/
usr/local/bin/
...
[root@node1 ~]# ls
backup.tar.bz2  bashusers  testfile  usr
```

### 내가 헷갈렸던 것 / 배운 것
- tar는 보안상 아카이브 저장 시 절대경로 맨 앞 `/`를 자동 제거 (`--absolute-names`/`-P` 안 쓰면 항상 상대경로로 저장)
- 압축을 어디서 푸느냐(`cd` 위치)가 결과 위치를 결정함
- 원래 위치로 복원하려면 반드시 `/`(루트)에서 풀어야 함
- 실습 부산물(`/root/usr`)은 rollback 시 `rm -rf /root/usr`로 정리

## 3. 파일 권한 + ACL 복합 문제 (natasha/harry + finance 그룹)

### Question
Copy the file /etc/fstab to /var/tmp/fstab. Configure the permissions of /var/tmp/fstab so that:
- the file /var/tmp/fstab is owned by the root user
- the file /var/tmp/fstab belong to the group root
- the file /var/tmp/fstab should not be executable by anyone
- the user "natasha" is able to read and write /var/tmp/fstab
- the user "harry" can neither write nor read /var/tmp/fstab
- all other users (current or future) have the ability to read /var/tmp/fstab

Allow the finance group to have Read and Execute (r-x) access to the /groups/accounting directory and any new files created within it.

### My Solution
```bash
# fstab 파일
cp /etc/fstab /var/tmp/fstab
chown root:root /var/tmp/fstab
chmod 644 /var/tmp/fstab
setfacl -m u:natasha:rw- /var/tmp/fstab
setfacl -m u:harry:--- /var/tmp/fstab

# finance 그룹 (사전 확인 + 준비)
getent group finance
mkdir -p /groups/accounting

# 현재 + 미래 파일 모두 적용 (콤마로 한 줄 처리)
setfacl -R -m g:finance:r-x,d:g:finance:r-x /groups/accounting
```

### Verification
```bash
[root@node1 ~]# getfacl /var/tmp/fstab
user::rw-
user:natasha:rw-
user:harry:---
group::r--
mask::rw-
other::r--

[root@node1 ~]# getfacl /groups/accounting/
user::rwx
group::r-x
group:finance:r-x
mask::r-x
other::r-x
default:user::rwx
default:group::r-x
default:group:finance:r-x   ← 최초 rw-로 잘못 들어갔던 걸 재수정 후 확인
default:mask::rwx
default:other::r-x
```

### 내가 헷갈렸던 것 / 배운 것
- `other`는 시스템 전체에 이미 정의된 카테고리라 "현재+미래 사용자" 조건이 chmod만으로 자동 충족됨
- 반면 특정 그룹(finance) 대상 조건은 자동 상속이 안 되므로 **반드시 default ACL(`d:`)**을 별도로 걸어야 "새로 생기는 파일"까지 커버됨
- `-R`(재귀, 현재 존재하는 것 대상)과 `-d`(default, 미래 생성분 대상)는 역할이 다르며 서로 대체 불가 — 둘 다 필요
- **mask** = named user/group ACL 권한의 상한선. `setfacl -m`으로 새 ACL 추가하면 자동 재계산되지만, 이후 `chmod g=`로 손대면 mask가 의도치 않게 줄어들 수 있음
- `getfacl` 출력에 `#effective:` 표시가 있으면 "설정값과 실제 적용값이 다르다"는 신호 — mask가 깎아먹은 것
- `-m` 뒤 여러 ACL 항목은 콤마(,)로 묶어 한 줄 처리 가능하나, 공백 없이 붙여 써야 함. 명령어 두 개를 잇는 건 `--`가 아니라 `;`/`&&`
- 실습 중 `d:g:finance:rw-`로 오타 → `getfacl`로 요구사항과 한 줄씩 대조해서 발견 및 수정 (`setfacl -m d:g:finance:r-x`로 덮어쓰기)

## 4. sudoers — 특정 명령어만 NOPASSWD 허용

### Question
"harry" user has access to set password for users without asking sudo password

### My Solution
```bash
visudo
# 아래 줄 추가
harry ALL=(ALL) NOPASSWD: /usr/bin/passwd
```

### Verification
(실습 미완료 — 다음 세션에 visudo 작성 후 `sudo -l -U harry`로 확인 예정)

### 내가 헷갈렸던 것 / 배운 것
- harry가 "전체 sudo 권한"을 갖는 게 아니라, sudoers 줄 끝에 명시된 `/usr/bin/passwd` **명령어 하나에 대해서만** sudo 사용 가능
- `NOPASSWD:`는 sudo 실행 시 harry 본인 로그인 비밀번호를 묻지 않겠다는 뜻
- 경로만 지정하면 인자 제한이 없어서, `sudo passwd root`처럼 다른 사용자(root 포함) 비밀번호도 변경 가능한 범위가 됨

## 원래 상태로 되돌리는 명령어 (Rollback)

```bash
# find/tar 실습 부산물 정리
rm -f /root/testfile
rm -rf /root/usr

# ACL 되돌리기
rm -f /var/tmp/fstab
setfacl -b /groups/accounting   # 모든 ACL 제거 (b = remove all)
rmdir /groups/accounting        # 비어있으면 삭제, 안 비어있으면 rm -rf

# sudoers (아직 미적용이면 생략)
# visudo에서 harry 줄 삭제
```
